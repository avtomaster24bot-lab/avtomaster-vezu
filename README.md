# АвтоМастер24 + ВЕЗУ — авто-услуги, грузоперевозки, визитки и магазины с заявками в WhatsApp

**Сайт:** https://avtomaster24bot-lab.github.io/avtomaster-vezu/
**Демо со всеми новыми функциями:** https://avtomaster24bot-lab.github.io/avtomaster-vezu/?demo=1 (выйти: кнопка «Выйти из демо» или `?demo=0`)

Это **АвтоМастер24 как есть** (дизайн, все функции, Supabase, демо-режим) из
[avtomaster24-web](https://github.com/avtomaster24bot-lab/avtomaster24-web), в который добавлено:

1. **🚚 Грузоперевозки** — новая категория рядом с СТО, эвакуатором, мойкой, запчастями и выездной помощью.
   Из проекта ВЕЗУ ([dogruz](https://github.com/avtomaster24bot-lab/dogruz)) перенесены форма заказа (что везём → машина →
   откуда/куда с геолокацией → когда → грузчики/доп. услуги → бюджет), тарифы по машинам, карточка водителя с QR.
2. **🪪 Визитка для любого бизнеса** (СТО, эвакуатор, мойка, магазин запчастей, выездной мастер, перевозчик):
   своя ссылка `card.html?id=N`, QR-код (SVG и PNG для печати), фото, слоган, услуги и цены, адрес и карта,
   часы работы и «Сейчас работает», кнопки **WhatsApp** и **Позвонить**, «В контакты» (vCard), «Поделиться»,
   быстрая заявка прямо с визитки. Владелец входит через Telegram и создаёт визитку сам — без ожидания модерации.
3. **🛍 Магазин в визитке.** У магазина запчастей в визитке есть кнопка «Магазин» → витрина `shop.html?id=N`
   в стиле «Учёт + Магазин» ([презентация](https://biznes-shablon.vercel.app/prezentaciya#3)):
   категории, поиск, сортировка, карточка товара, остатки, корзина, оформление. Товары ведёт владелец в
   Кабинете → «Магазин». Можно вместо встроенной витрины указать ссылку на свой внешний магазин (`https://…`).
4. **📲 Все заявки и заказы — в WhatsApp владельца.** Любая заявка (с визитки, с витрины, из приложения, от гостя
   без входа) открывает WhatsApp владельца с готовым аккуратным текстом (`wa.me/…?text=`) и одновременно
   сохраняется в базе: владелец видит её в Кабинете → «📲 WhatsApp» и ведёт по статусам
   *Новая → В работе → Выполнена / Отменена*. Заявки «без исполнителя» уходят диспетчеру сервиса
   (номер `DISPATCH_WHATSAPP` в `config.js`) и видны админу во вкладке «📢 Диспетчер».
5. **💬 Чат по заказу на сайте (как переписка в боте).** Клиент не уходит с сайта: после заявки с визитки, витрины или
   из приложения открывается страница `order.html?id=N&t=<секрет>` — переписка с исполнителем (текст, фото, **предложение
   цены → «Принять цену»**, системные сообщения о статусе). Гостю вход не нужен: секретная ссылка сохраняется в браузере
   («💬 Мои заказы»), а с другого устройства можно вернуться по номеру телефона. Владелец видит все чаты в Кабинете →
   «💬 Заявки и чаты» (метка «новое сообщение», уведомления браузера).
   Цикл: **новая → уточнение → цена согласована → в работе → выполнено → оплачено → оценено → закрыт.**
   Когда заказ оплачен и оценён, он закрывается, а **переписка удаляется через 3 дня** (об этом написано в чате);
   итог заказа, согласованная цена, оценка и отзыв остаются. Оценка сразу попадает в рейтинг визитки и в блок
   «Отзывы по заказам».
   **WhatsApp теперь — уведомление и запасной канал:** в каждом сообщении, которое формирует сайт, есть ссылка на чат
   заказа (или хотя бы на сайт). Telegram-уведомление владельцу — готовая функция `supabase/functions/am-notify`
   (не развёрнута).
6. **🌍 Готовность к другим странам.** Регион (валюта, формат телефона, карты, способы оплаты), мессенджер и
   бэкенд вынесены в адаптеры — см. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
7. **💳 Тарифы** (`#/tariffs`): Визитка — бесплатно, Про, Магазин, печать QR-наклеек; тарифы грузоперевозок.

Исходный ВЕЗУ целиком (с историей коммитов) лежит в [`legacy/vezu/`](legacy/vezu/) — как справочник; на сайт он не публикуется.
История обоих проектов сохранена в git (слияние `--allow-unrelated-histories`).

## Как это работает для каждого типа

| Тип | Визитка | Быстрая заявка с визитки → WhatsApp | В приложении |
|---|---|---|---|
| 🔧 СТО | услуги и цены, направления, фото, отзывы | машина, что случилось, когда удобно | заявка «всем СТО» или выбранной, офферы, чат |
| 🚛 Эвакуатор | цены, зона работы | откуда (📍 геолокация), куда, что за машина | срочная заявка, первый принявший едет |
| 🧽 Мойка | услуги, боксы | услуга, кузов, время | цена и время от мойки → подтверждение |
| ⚙️ Запчасти | **кнопка «🛍 Магазин»** → витрина | какая деталь, VIN/машина | анонимные предложения цен |
| 🆘 Выездная помощь | тип мастера | что случилось, где (геолокация) | срочная заявка |
| 🚚 Грузоперевозки | машина (фото, грузоподъёмность, цена/час), грузчики, районы | что везём, откуда/куда, когда, бюджет | заявка всем перевозчикам города (живёт 2 часа) |

## Магазин ↔ витрина: как привязано

- Витрина принадлежит организации (`am_products.provider_id`), а организация — владельцу (`am_providers.owner_id` = Telegram-аккаунт).
  Добавлять и менять товары может только владелец (RLS `am_owns`) или админ.
- В визитке кнопка «Магазин» ведёт на `shop.html?id=<организация>` (если включена встроенная витрина) или на внешний
  `store_url` (например, отдельный сайт «Учёт + Магазин» этого магазина).
- Заказ с витрины → WhatsApp магазина с составом, суммой, способом получения и оплаты (Kaspi / наличные / карта)
  + сохраняется как лид `kind=order, source=shop` с позициями в `payload`.
- Полноценный «Учёт + Магазин» (склад, налоги 910, Kaspi-выгрузка) — отдельный проект на Next.js/Prisma; эта витрина —
  его облегчённая часть для визитки. Связать их можно через `store_url` или синхронизацию товаров (см. ARCHITECTURE.md).

## Режимы

- **БОЕВОЙ** — сейчас на сайте: база Supabase, вход через Telegram. Пока не выполнена миграция `04` (см. ниже),
  визитки/магазин/лиды в боевом режиме скрыты, а заявки гостей и грузоперевозки просто открывают WhatsApp

- **ДЕМО** — `?demo=1`. Всё работает в браузере (localStorage), организации и товары вымышленные, номера — демо.
  Вверху кнопки «Клиент / Исполнитель / Админ / Сбросить / Выйти из демо». Примеры:
  визитка перевозчика `card.html?id=14&demo=1`, витрина `shop.html?id=8&demo=1`, внешний магазин `card.html?id=9&demo=1`.

  «Глазами клиента / Глазами исполнителя» в демо-полосе переключают сторону; «⏩ перемотать 4 дня» показывает удаление переписки.

## Свой бот для входа

Сейчас кнопка входа использует бота **@VeloMaster24bot** (его функция входа уже работает в Supabase, домен `avtomaster24bot-lab.github.io` у него привязан).
Чтобы входить через **@TochkaSborki_A24_bot**:
1. В @BotFather: `/setdomain` → выберите бота → `avtomaster24bot-lab.github.io`.
2. Разверните в Supabase копию функции `telegram-auth` из репозитория velomarket под именем `am-telegram-auth`
   и задайте ей секрет `TELEGRAM_BOT_TOKEN` (токен бота АвтоМастер24 — только в Supabase, не в GitHub).
3. В `site/js/config.js` поменяйте `TELEGRAM_AUTH_URL` на `…/functions/v1/am-telegram-auth` и `TELEGRAM_LOGIN_BOT` на `TochkaSborki_A24_bot`.

## Безопасность и личные данные

- В репозитории **нет** токенов, паролей, телефонов и Telegram ID пользователей. Из базы бота взяты только справочники
  (города, 17 направлений и 109 уточнений, услуги, марки, модели, интервалы ТО, справочный прайс).
- В `config.js` только публичный anon-ключ Supabase — он безопасен, потому что в базе включён RLS на всех таблицах.
- Телефон клиента видит **только** исполнитель, который принял заявку (функция `am_client_contact`). Для запчастей поставщики анонимны, пока клиент не выбрал предложение.
- Исполнитель не может сам себе поменять рейтинг, город или включиться после отключения (триггер в базе). Все смены статусов — только через функции с проверками.

- Заявки гостей без входа принимает только функция `am_create_lead` (проверка, лимит 10 заявок за 10 минут с адреса,
  20 в час с одного номера). Читать лиды может только владелец организации или админ; гости — нет.
- Ссылка на внешний магазин принимается только `https://`.
- Чат заказа: секрет клиента не виден даже владельцу организации (владелец не может «оценить сам себя» через ссылку клиента);
  сообщения читаются только через функции с проверкой секрета или владения; по realtime-каналу идёт только «пинг» без текста;
  не больше 20 сообщений в минуту; фото сжимаются в браузере до ~1024 px и удаляются вместе с перепиской.
