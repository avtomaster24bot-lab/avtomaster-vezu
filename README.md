# АвтоМастер24 — веб-версия сервиса (сайт на GitHub Pages)

Тот же сервис, что в Telegram-боте **@TochkaSborki_A24_bot**, только в браузере:
**https://avtomaster24bot-lab.github.io/avtomaster24-web/**

Сайт работает и для **клиентов**, и для **исполнителей** (СТО, эвакуаторы, мойки, магазины запчастей, выездные мастера), и для **администраторов**.
Открывается на телефоне и компьютере. Может работать как Telegram Mini App.

## Два режима

- **ДЕМО** (сейчас, пока таблицы в базе не созданы). Всё кликается: вверху кнопки «Клиент / Исполнитель / Админ».
  Данные хранятся только в вашем браузере, организации вымышленные. Чужие демо-исполнители «откликаются» сами через 4 секунды.
- **БОЕВОЙ** включается сам, как только в Supabase появятся таблицы `am_*`. Вход через Telegram, общая база для всех.

## Как включить боевой режим (5 минут)

1. Откройте https://supabase.com/dashboard → проект VeloMarket (`wzhwnffdylhkmapijkrn`) → **SQL Editor** → **New query**.
2. Скопируйте весь файл [`supabase/all_in_one.sql`](supabase/all_in_one.sql), вставьте, нажмите **Run**. Должно быть «Success».
   (Таблицы с префиксом `am_` не трогают VeloMarket.)
3. Откройте сайт, нажмите «Войти» и войдите через Telegram.
4. Сделайте себя администратором: в SQL Editor выполните
   `select am_make_admin('ваш_username_в_telegram');`
   Региональный админ города: `select am_make_admin('username', 'Талдыкорган');`
5. Перенести организации из бота (по желанию): на своём компьютере
   `python3 tools/export_providers.py avtomaster.db` → файл `private/providers.sql` → вставить в SQL Editor → Run.
   Телефоны организаций в GitHub не попадают (папка `private/` в `.gitignore`).
   Владельцы организаций подают заявку «Для бизнеса» на сайте — после одобрения у них появляется Кабинет.

## Свой бот для входа

Сейчас кнопка входа использует бота **@VeloMaster24bot** (его функция входа уже работает в Supabase, домен `avtomaster24bot-lab.github.io` у него привязан).
Чтобы входить через **@TochkaSborki_A24_bot**:
1. В @BotFather: `/setdomain` → выберите бота → `avtomaster24bot-lab.github.io`.
2. Разверните в Supabase копию функции `telegram-auth` из репозитория velomarket под именем `am-telegram-auth`
   и задайте ей секрет `TELEGRAM_BOT_TOKEN` (токен бота АвтоМастер24 — только в Supabase, не в GitHub).
3. В `site/js/config.js` поменяйте `TELEGRAM_AUTH_URL` на `…/functions/v1/am-telegram-auth` и `TELEGRAM_LOGIN_BOT` на `TochkaSborki_A24_bot`.

## Безопасность и личные данные

- В репозитории **нет** токенов, паролей, телефонов и Telegram ID пользователей. Из базы бота взяты только справочники
  (города, 17 направлений и 109 уточнений, услуги, марки, модели, интервалы ТО, справочный прайс).
- В `config.js` только публичный anon-ключ Supabase — он безопасен, потому что в базе включён RLS на всех таблицах.
- Телефон клиента видит **только** исполнитель, который принял заявку (функция `am_client_contact`). Для запчастей поставщики анонимны, пока клиент не выбрал предложение.
- Исполнитель не может сам себе поменять рейтинг, город или включиться после отключения (триггер в базе). Все смены статусов — только через функции с проверками.
