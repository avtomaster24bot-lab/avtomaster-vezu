# ВЕЗУ — грузоперевозки до 3 тонн и визитки водителей

Статический сайт (GitHub Pages, без сервера).

- `index.html` — главная: заказ в WhatsApp за 2 касания.
- `card.html?d=…` — цифровая визитка водителя (данные зашиты в ссылку). Пример: `card.html?demo`.
- `new.html` — конструктор визитки: ссылка, QR (PNG), печать визиток A4 и наклейки на авто.

Номер WhatsApp для заявок с главной задаётся в `js/common.js` (`SITE_PHONE`).
QR генерируется в браузере библиотекой `js/vendor/qrcode.js` (MIT).
